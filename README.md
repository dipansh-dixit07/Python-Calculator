# 🧮 Simple Calculator

A beginner Python project that performs basic arithmetic operations from the command line.

## 📌 About

This is a simple calculator built in Python that takes two numbers and an operator as input and returns the result. Built as a school project in Class 9 to learn Python fundamentals like variables, user input, conditionals, and error handling.

## ⚙️ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`) with divide-by-zero protection

## 🚀 How to Run

Make sure Python is installed on your system. Then:

```bash
python calculator.py
```

**Example usage:**
```
Enter the number: 10
Enter the operator (+, -, *, /): *
Enter the number: 5
Your result is 50
```
